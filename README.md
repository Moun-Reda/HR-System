# HR-System
This is a console-based Human Resources Management System built in Python. It allows users to manage employee records including adding, updating, searching, deleting, and tracking employment status. The system uses lists to store employee data and includes date validation, status toggling, and ID-based operations.

🚀 Features
- 🔹 Add new employees with validated hire dates
- 🔹 View all active or retired employees
- 🔹 Search employees by ID
- 🔹 Update employee details interactively
- 🔹 Toggle employment status (Active ↔ Retired)
- 🔹 Delete employee records safely
- 🔹 Input validation for salary and date formats


🧪 Data Validation
- Hire Date must be entered in dd/mm/yyyy format.
- Salary must be a valid float and not negative or zero.
- Empty inputs are skipped during updates.
- Deletion prompts for confirmation before proceeding.
